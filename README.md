# site-finder — поиск сайта организации по ИНН

Пайплайн на Python: принимает ИНН российской организации (ЮЛ или ИП), ищет в интернете её
основной сайт, проверяет кандидатов по реквизитам и с помощью LLM (GigaChat) и возвращает домен
или `null`.

```
$ uv run python -m site_finder 7721581040
{"domain": "dadata.ru", "sites": ["dadata.ru"]}

$ uv run python -m site_finder '{"inn": "502240684873"}'
{"domain": null, "sites": []}
```

`domain` — основной сайт (формат из задания), `sites` — все подтверждённые домены
(совместимо с полем `data.sites[]` в ответе DaData «Организация по ИНН»).

## Как работает

```
ИНН → валидация (контрольная сумма)
    → справочник data/directory.csv: если ИНН уже проверялся — ответ сразу
    → карточка ЕГРЮЛ/ЕГРИП (название, ОГРН, адрес, e-mail)
    → веб-поиск: Exa + DuckDuckGo по шаблонным запросам ("ИНН", "ОГРН", "название + город")
    → кандидаты: домены из выдачи + домены, упомянутые на страницах с ИНН компании
                 (карточки агрегаторов: "Сайт: …", "E-mail: info@…") + домен почты из ЕГРЮЛ
    → проверка (код): главная + контакты/реквизиты/политика ПДн → поиск ИНН, ОГРН, названия
    → GigaChat: вердикт по каждому кандидату (own_site / group_site / third_party_mention / unrelated)
                + дословная цитата; цитата проверяется кодом
    → правило: ИНН/ОГРН на сайте + подтверждение LLM, либо название + независимый источник + LLM
    → нет подтверждённого сайта → GigaChat предлагает новые запросы, ещё одна итерация
    → ответ + запись в справочник + трассировка logs/<ИНН>.json
```

Подробное описание решений — в PDF с ответом на задание.

## Установка и запуск

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env   # заполнить ключи GigaChat, DaData, Exa
uv run python -m site_finder 7721581040 -v
```

Параметры CLI:

| флаг | что делает |
|---|---|
| `-v` | показать кандидатов, флаги проверки (И — ИНН, О — ОГРН, Н — название) и решения |
| `--refresh` | искать заново, даже если ИНН есть в справочнике |
| `--no-directory` | не читать и не писать справочник |
| `--no-llm` | без LLM: только проверка реквизитов (базовая линия) |

Можно передать несколько ИНН: `python -m site_finder 7721581040 7707083893`.

Оценка качества на размеченной выборке (справочник при этом отключён):

```bash
uv run python eval.py                  # режимы full, no_retry, no_llm
uv run --group dev pytest              # юнит-тесты (без сети)
```

## Структура

| файл | роль |
|---|---|
| `site_finder/__main__.py` | CLI |
| `site_finder/pipeline.py` | оркестрация шагов, итерации, трассировка |
| `site_finder/egrul.py` | карточка ЕГРЮЛ/ЕГРИП (в прототипе — через API DaData) |
| `site_finder/search.py` | шаблонные запросы, Exa и DuckDuckGo |
| `site_finder/candidates.py` | сбор и ранжирование доменов-кандидатов, распознавание страниц-каталогов |
| `site_finder/verify.py` | загрузка сайта (httpx, запасной вариант — Exa contents), поиск реквизитов |
| `site_finder/matching.py` | поиск ИНН/ОГРН/названия в тексте, фрагменты, проверка цитат |
| `site_finder/llm.py` | GigaChat: вердикт по кандидатам и генерация новых запросов |
| `site_finder/rules.py` | правило принятия решения и выбор основного сайта |
| `site_finder/directory.py` | справочник ИНН → сайты (CSV) |
| `site_finder/domains.py` | нормализация доменов, извлечение из текста, площадки низкого приоритета |
| `site_finder/inn.py` | проверка контрольной суммы ИНН |
| `site_finder/cache.py` | дисковый кэш ответов внешних сервисов |
| `eval.py`, `data/eval.csv` | оценка качества и эталонная выборка |
| `data/directory.csv` | справочник (создаётся при работе) |
| `certs/russian_trusted_root_ca.pem` | корневой сертификат НУЦ Минцифры для TLS к API GigaChat |
