Выводы

  • LLM повышает точность: без неё («на сайте есть ИНН/ОГРН — принять») precision 83–85% — принимаются агрегаторы, санкционные списки, тендерные площадки, чужие политики ПДн; с вердиктом LLM — 95–97%. На отложенной выборке цена — recall 85% → 81%.
  • Вторая итерация (запросы от LLM) на dev подняла recall 89% → 95%, на отложенной не изменила ничего: эффект не подтверждён.
  • Компаниям без сайта сайт не приписан ни разу (верные null — 100% на обеих выборках), включая ИП с тёзкой-писательницей и банкрота с реквизитами на чужом юридическом сайте.
  • Ошибки отложенной выборки (не исправлялись, чтобы оценка оставалась честной): «Ашан» — принята страница тендерной площадки; пропуски: Wildberries и cifrus.ru (сайты на JS, бренд латиницей), sst72.ru (модель подмешала в цитату индекс из карточки), lomonosov.school (спорно: на сайте ИП лишь принимает платежи за ООО).
  • Стоимость ИНН: медиана 76 с и ~4,5 тыс. токенов GigaChat, 3–6 запросов к Exa; вторая итерация — в ~40% случаев.
  • Ограничения оценки: выборки малы (95%-й интервал Уилсона для precision 21/22 — 78–99%), положительные примеры малых компаний смещены к сайтам с реквизитами.
